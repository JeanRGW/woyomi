# @woyomi/server

Optional self-hosted backend for woyomi's web build. A [Hono](https://hono.dev)
app providing three independent features:

| Endpoint | Purpose | Auth |
|---|---|---|
| `GET /health` | liveness probe | — |
| `POST /api/scrape` | CORS-free fetch proxy for plugins in web mode | off by default (`SCRAPE_ENABLED=true`), optional `SCRAPE_TOKEN` (sent as `Bearer`) |
| `GET/PUT /api/sync/:user` | library/progress JSON sync (app is the source of truth; this is a sync bus, not a database) | `SYNC_TOKEN` (required, `Bearer`) |
| `GET /repo`, `GET /repo/:file` | plugin repository (merged `index.json` + bundles) | — |

## Running

```sh
pnpm install && pnpm build   # from the monorepo root
cd apps/server
SYNC_TOKEN=$(openssl rand -hex 32) DATA_DIR=./data PORT=8787 pnpm dev
```

For production, run `node dist/index.js` behind a reverse proxy with HTTPS.

## Environment

| Variable | Default | Description |
|---|---|---|
| `PORT` | `8787` | HTTP listen port |
| `DATA_DIR` | `./data` | per-user sync JSON files (create it; not committed) |
| `SYNC_TOKEN` | — (required for sync) | shared Bearer token for `/api/sync/*` |
| `SCRAPE_ENABLED` | `false` | opt in to the fetch proxy |
| `SCRAPE_TOKEN` | — | optional shared Bearer token for `/api/scrape` |
| `PLUGIN_REPO_DIR` | monorepo root | serve a plugin repo from `<dir>/plugins/*/dist`; missing/empty dirs yield an empty index |

## Plugin repository

Point `PLUGIN_REPO_DIR` at a directory containing built plugin packages
(`plugins/<name>/dist` with `<id>.plugin.js`, `<id>.plugin.json`, and an
`index.json` generated by `@woyomi/plugin-builder`'s `gen-repo`). The `/repo`
endpoint merges each `index.json` and serves the bundles; users add
`http://your-host:8787/repo` in the app's Plugins screen.

## Hardening notes

- The scrape proxy rejects loopback/private/link-local targets (SSRF
  blocklist), caps response size, and times out — but has **no per-user rate
  limits**. Keep `SCRAPE_TOKEN` set and don't expose it publicly.
- `SCRAPE_ENABLED=false` by default so a default deployment is not an open
  proxy.
